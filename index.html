Card de Estudos

Conceitos de Programação:

A programação é o processo de criar um conjunto de instruções que dizem a um computador como realizar uma tarefa.

Conceitos de HTML:

O HTML (Linguagem de Marcação de Hipertexto) é a linguagem de marcação padrão para criar páginas da web.

Conceitos de CSS:

O CSS (Folhas de Estilo em Cascata) CSS é uma linguagem de folhas de estilo, usada para definir a apresentação dos elementos HTML.

Conceitos de JavaScript:

O JavaScript é uma linguagem de programação interpretada e dinâmica, utilizada principalmente para criar interatividade em páginas da web.
